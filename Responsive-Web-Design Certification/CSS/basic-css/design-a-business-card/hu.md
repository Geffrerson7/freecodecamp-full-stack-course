Diseña una tarjeta de presentación
==================================

Aprobado

Construye una app que sea funcionalmente similar a este proyecto de ejemplo. Trata de no copiar el proyecto de ejemplo, dale tu propio estilo personal.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1.  Deberías tener un `div` con un atributo `class` con un valor de `business-card` que contenga todos los otros elementos.
2.  Dentro del elemento `.business-card`, debe haber un elemento `img` con un atributo `class` con un valor de `profile-image`. Puedes establecer la fuente de la imagen en `https://cdn.freecodecamp.org/curriculum/labs/flower.jpg` si lo deseas. Debe haber un `alt` con una descripción significativa.
3.  Dentro del elemento `.business-card`, después del elemento `img`, debería haber tres elementos `p` con un atributo `class` que tenga, respectivamente, un valor de `full-name`, `designation`, y `company`.
4.  El primer elemento `p` debe contener tu nombre.
5.  El segundo elemento `p` debe contener tu designación.
6.  El tercer elemento `p` debe tener el nombre de tu empresa.
7.  Debe haber un elemento `hr` debajo del tercer elemento `p`.
8.  Después del elemento `hr`, debe haber dos elementos `p`. En el primer elemento `p`, deberías tener una dirección de correo electrónico como texto. En el segundo elemento `p`, el texto debe ser un número de teléfono.
9.  Después de los dos elementos `p`, debe haber un elemento `a` con una clase `portfolio-link`, el texto `Portfolio` y debe enlazar a una URL válida.
10.  Debe haber un elemento `hr` después del elemento `a` que contiene el enlace del portafolio.
11.  Deberías tener otro elemento `div` con un atributo `class` con un valor de `social-media`. Dentro de este elemento, debe haber un elemento `h2` con el texto `Connect with me`.
12.  Dentro del os elementos `.social-media`, debe haber tres elementos `a`. Los elementos `a` deben tener el texto `Twitter`, `LinkedIn` y `GitHub` respectivamente con enlaces a sitios web válidos.
13.  Deberías enlazar la hoja de estilo `styles.css` usando la etiqueta `link` en la sección `head` del archivo HTML.
14.  El fondo de tu página debería ser `rosybrown`. La fuente general debe ser `Arial`, con una alternativa de `sans-serif`.
15.  El selector `.business-card` debería tener propiedades para establecer el elemento con un ancho de `300px` y un color de fondo a tu elección. También deberías establecer un `padding` de `20px` alrededor y un `margin` superior de `100px`. El texto debería estar alineado al centro y el tamaño de la fuente debería ser `16px`. Los márgenes izquierdo y derecho deben establecerse en `auto`.
16.  El selector `.profile-image` debería tener una propiedad `max-width` con un valor de `100%`.
17.  Todos los elementos `p` deben tener un `margin` superior e inferior de `5px`.
18.  Todos los enlaces en la página no deberían estar subrayados.
