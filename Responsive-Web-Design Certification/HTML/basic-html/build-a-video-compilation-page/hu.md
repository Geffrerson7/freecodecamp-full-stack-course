Crea una página de compilación de vídeo
=======================================

Aprobado

Construye una app que sea funcionalmente similar a este proyecto de ejemplo. Trata de no copiar el proyecto de ejemplo, dale tu propio estilo personal.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1.  Debes tener un elemento `main` como el único hijo del elemento `body`.
2.  Debes tener un elemento `h1` con el tema de tu página.
3.  Debes tener un párrafo que introduzca el tema de tu página debajo del elemento `h1`.
4.  Debes tener tres elementos `section` debajo de tu primer párrafo.
5.  Cada sección debe contener un elemento `h2`, un párrafo y un elemento `iframe`, en este orden.
6.  Los tres elementos `iframe` deben tener un atributo `src` establecido en un video válido.
7.  Cada elemento `iframe` también debe tener un atributo `title` para describir el contenido incrustado, y un atributo `height` y un atributo `width` para establecer el tamaño adecuado del elemento.
